# Language comparison cheat sheet

Use these tables to look up familiar syntax. For explanations and runnable
examples, read [Toit for programmers](/language/toitversus) or the guides for
[Python](/language/from-python), [C/C++](/language/from-cpp), and
[JavaScript](/language/from-javascript).

The entries compare common tasks, not identical semantics. In particular,
Toit annotations check values at runtime, only `false` and `null` are falsy,
and a block can return from its enclosing function. Code fragments assume
any required imports and enclosing declarations.

A final Toit binding does not freeze its object. Python constants are a naming
convention; JavaScript class fields are not made final by `static`.

C++ type tests above assume a polymorphic base and a pointer. Toit object
references are managed values, and `is` does not require a pointer cast.
C/C++ `#include` is textual inclusion; Toit imports load library declarations.

Python `//` floors the result; Toit integer `/` truncates toward zero. JavaScript
`Number` division is floating point, and its bitwise operators use 32-bit values;
Toit integers are signed 64-bit values. The tables show the closest common
spelling, not a promise that porting the expression preserves every edge case.
