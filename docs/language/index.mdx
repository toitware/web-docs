# Learn Toit

Toit is an object-oriented, garbage-collected language designed for
microcontrollers. You can also run programs on your computer to learn the
language without connecting hardware.

## Choose your starting point

| Your experience | Start here | What you will learn |
| --- | --- | --- |
| New to programming, or want a guided first program | [Beginner tutorial](/language/beginner) | Build and run a temperature report, from variables to functions and a small class. |
| Already comfortable programming | [Toit for programmers](/language/toitversus) | How calls, types, blocks, objects, and tasks work, and what those choices imply. |
| Coming from JavaScript or TypeScript | [Toit for JavaScripters](/language/from-javascript) | Replace assumptions about callbacks, promises, objects, truthiness, and numbers. |
| Coming from Python | [Toit for Python programmers](/language/from-python) | Understand the differences behind the familiar indentation. |
| Coming from C or C++ | [Toit for C and C++ programmers](/language/from-cpp) | Move from native memory and threads to managed objects and cooperative tasks. |

## Look up a language feature

The [language reference](/language/reference) is organized by topic. It assumes
you can already read a small Toit program; it is not a sequence of lessons.
Use it for syntax rules, edge cases, and more detailed examples.

## Use Toit in a project

After learning the language, use the [package quick start](/language/package/pkgguide)
to add dependencies, or [run on your device](/getstarted/device) to connect an
ESP32. The [hardware and networking tutorials](/tutorials) assume basic Toit
knowledge and list their additional setup requirements.
