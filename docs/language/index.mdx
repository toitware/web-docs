# Learn Toit

<span id="language-basics" />

Toit is an object-oriented, garbage-collected language for scripting on your
computer and programming connected devices. You can use the same language
for a command-line tool, a network service, or an application on a microcontroller.

## Choose your starting point

| Your experience | Start here | What you will learn |
| --- | --- | --- |
| Already comfortable programming | [Toit for programmers](/language/toitversus) | A complete language tour, with comparisons to C/C++, JavaScript, Python, and Java/Kotlin. |
| New to programming | [Beginner lessons](/language/beginner) | Build a temperature report step by step, then add lists, functions, and objects. |

The programmer's tour explains Toit directly; you do not need to know every
language used for comparison. Familiar features are covered briefly, while
Toit-specific concepts receive more explanation and examples.

The [C/C++ introduction](/language/from-cpp) covers the language from a native
programmer's starting point. The [JavaScript](/language/from-javascript) and
[Python](/language/from-python) guides focus on differences from those languages.
Use the [comparison cheat sheet](/language/cheat-sheet) for side-by-side syntax
lookup.

## Use Toit in a project

For a host script or command-line tool, save your program in a `.toit` file
and run it with `toit run`. Use the
[package quick start](/language/package/pkgguide) to add dependencies.

For an ESP32 application, [run on your device](/getstarted/device).
The [hardware and networking tutorials](/tutorials) list their additional setup
requirements.
